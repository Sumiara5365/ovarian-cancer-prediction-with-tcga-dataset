## 📌 Project Overview

This project focuses on ovarian cancer stage classification using multi-omics data from The Cancer Genome Atlas (TCGA-OV). The study explores molecular and clinical features to classify ovarian cancer into different disease stages using machine learning techniques.

Multiple machine learning models are evaluated to identify effective approaches for stage classification, while explainability techniques are used to investigate important features and potential biomarkers.
